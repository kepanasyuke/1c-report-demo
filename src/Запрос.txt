// Почему записан именно так (тезисы для собеседования):
//  1. Одно обращение к виртуальной таблице "ОстаткиИОбороты" вместо двух

//     настройками СКД, поэтому не меняют текст запроса и не сбрасывают
//     кэш СУБД от выбора конкретного значения.
//  4. Ни одного обращения через точку к полям ссылочных типов: только
//     поля набора, поэтому запрос не превращается в цепочку LEFT JOIN.
//------------------------------------------------------------------------------
